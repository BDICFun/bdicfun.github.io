## 内容贡献

如果您也想为本项目贡献内容，我们非常欢迎！可以通过以下方式参与：

### 贡献类型

- **课程笔记**：分享您的学习笔记和总结
- **学习心得**：提供学习方法和经验建议  
- **资料整理**：收集和整理课程相关资料
- **技术支持**：改进网站功能和用户体验
- **内容校对**：修正错误信息和完善内容

### 如何贡献
[如何贡献](./how-to-contribute.md)

### 贡献准则

!!! tip "贡献要求"

    - 确保内容的原创性和准确性
    - 遵守学术诚信原则
    - 使用清晰、友好的语言
    - 提供充分的上下文和说明


如果您有兴趣，请通过邮箱 `bdicfun@gmail.com` 联系我们！
