### 2026 年投稿

#### 期末考试

期末为开卷考试，可携带 5 张 A4 纸，正反面均可使用，允许打印。试卷共 4 道大题，取其中得分最高的 3 道计分。

首年考试中，期末题目与 Practise Sheet、Assignment 中的题目较为重合，另有 6–8 分的 Explain 题此前未见过的。
